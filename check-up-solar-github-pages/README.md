# Check-up Solar Trindade

Apresentação em HTML/CSS (13 slides) com o plano de entrada no setor solar em Trindade-GO e região.

Navegação: setas do teclado, botões na parte de baixo ou deslizando no celular. Cada slide tem um link próprio, por exemplo `#mercado` e `#30dias`.

## Arquivos

- `index.html`: os slides
- `styles.css`: o visual, com tema claro e escuro automáticos
- `script.js`: a navegação
- `.nojekyll`: faz o GitHub Pages servir os arquivos como estão

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub, por exemplo `check-up-solar`.
2. Envie estes 4 arquivos para a raiz do repositório.
3. Abra **Settings → Pages**. Em *Source*, escolha **Deploy from a branch**, depois a branch `main` e a pasta `/ (root)`, e clique em **Save**.
4. Depois de 1 a 2 minutos, o site fica no ar em `https://flupdigital-cmd.github.io/check-up-solar/`.

Para testar no seu computador, basta abrir o `index.html` no navegador.
